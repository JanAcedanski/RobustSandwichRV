# RobustSandwichRV: certified sample robustness values

A pure-R implementation of omitted-variable sensitivity analysis for
linear regression with classical, HC0, HC1, CR0, and CR1 standard
errors. The recommended workflow is benchmark-bounded observed-control
calibration; point-conditioned procedures remain available for
diagnostics.
