# Evaluate nested benchmark bands with witness reuse

Evaluate nested benchmark bands with witness reuse

## Usage

``` r
rv_cal_bounded_sequence(cache, benchmarks, ...)
```

## Arguments

- cache:

  An `rv_cache`.

- benchmarks:

  A list of benchmark objects or magnitudes.

- ...:

  Arguments passed to
  [`rv_cal_bounded()`](https://JanAcedanski.github.io/RobustSandwichRV/reference/rv_cal_bounded.md).
