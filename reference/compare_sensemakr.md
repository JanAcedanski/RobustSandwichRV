# Compare the classical implementation with `sensemakr`

Compare the classical implementation with `sensemakr`

## Usage

``` r
compare_sensemakr(model, treatment, alpha = 0.05)
```

## Arguments

- model:

  An `lm` object.

- treatment:

  Treatment coefficient name.

- alpha:

  Two-sided test level.

## Value

A data frame with both conventional robustness values.
