# Conventional full-model t statistic from CH geometry

Conventional full-model t statistic from CH geometry

## Usage

``` r
classical_ch_t(cache, x, y, null = 0, adverse = TRUE)
```

## Arguments

- cache:

  An `rv_cache`.

- x:

  Treatment-side partial R-squared.

- y:

  Outcome-side partial R-squared.

- null:

  Null coefficient value.

- adverse:

  If `TRUE`, select the coefficient-reducing sign.
