# Code of Conduct

Contributors and users are expected to communicate respectfully, document
technical claims, and distinguish reproducible numerical evidence from
conjecture. Harassment, personal attacks, and discriminatory conduct are not
accepted. Project maintainers may edit or remove contributions that violate
these standards.

Methodological disagreement is welcome. Reports should identify the estimator,
critical-value convention, calibration mode, software version, and a
reproducible example whenever possible.
